# attrapay-ops-intelligence
Operations Intelligence Dashboard for Quality Control &amp; Strategy Analytics -  Python + SQL

## Strategy & Operations Case Study

This dashboard simulates a real-world Ops Intelligence tool to reduce QC failures and optimize supplier performance.

### Business Problem
- 15%+ defect rate from critical suppliers
- Manual reporting 5 hrs/week
- No visibility on risky suppliers

### My Solution
1. Built QC analytics engine in Python
2. Created supplier risk scoring model
3. Automated ops dashboard with Streamlit
4. Wrote 6 SQL queries for ops bottlenecks

### Tech Stack
- Python, Pandas, Streamlit
- SQL (PostgreSQL analytics)
- Git, GitHub

### Impact
- Identified 2 suppliers causing 60% failures
- Mock reduction: 15% -> 4% defect rate
- Saves 5 hrs/week reporting

### How to Run
pip install -r requirements.txt
streamlit run app.py
